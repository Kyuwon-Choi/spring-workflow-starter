# 질문·계획 skill

자료/담당자 답을 요구와 실행 계획으로 연결한다. [fde-discovery](fde-discovery/SKILL.md)는 자료/담당자 답에서 다음 질문과 근거 있는 요구를 만들고, [fde-planning](fde-planning/SKILL.md)은 요구를 코드 적합성·시간·검증·제출 계획으로 바꾼다. 단일 대화에서 단계별로 사용한다.

지원하는 로컬 Codex 환경에서 이 두 디렉터리를 자신의 skills 경로(기본 ~/.codex/skills/)에 설치할 수 있다. 같은 이름이 이미 있으면 먼저 내용을 비교하고 덮어쓰지 않는다. 설치한 환경의 실제 skill 사용법/재탐색 방법을 따른다. 설치하지 않아도 SKILL.md/참고 파일을 읽어 작업 절차로 사용할 수 있다.

```text
$fde-discovery
과제/자료: [원문·경로]
이미 받은 답: [실제 답]
남은 시간: [값]
다음 질문과 그 답이 바꾸는 조건을 골라줘. 답을 대신 만들지 마.
```

```text
$fde-planning
요구 기록: [실제 경로]
기존 코드/허용 키트: [경로]
작업 종료/전체 마감: [값]
요구별 완료 조건·재사용 판단·첫 흐름·검증·제출 시간을 계획해줘.
```

[전체 작업 절차](../docs/WORKFLOW.md)와 [단계별 프롬프트](../docs/PROMPTS.md)를 함께 사용한다. 평가의 실제 자료/AI 사용 규칙을 따른다. 평가에서는 개인 Skills 반입·AI 사용 규칙을 먼저 확인한다.
