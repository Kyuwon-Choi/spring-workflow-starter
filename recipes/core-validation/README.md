# 핵심 계산을 검증하는 작은 예제

별도 패키지 설치 없이 Python 3.10+에서 실행한다. 이 예제는 자원별 수용 개수와 배정 비용이 있는 작은 모델이다. 실제 과제의 알고리즘이나 정책을 대신하지 않으며 생성 앱에 자동 복사되지 않는다.

```bash
python3 -m unittest discover -s recipes/core-validation -v
```

`decision.py`는 입력 순서대로 가장 싼 허용 자원을 고르는 `greedy`, 모든 작은 배정을 조사하는 `exact_tiny`, 필수 조건/비용을 다시 계산하는 `evaluate`를 분리했다. 각 작업은 자원 하나에 배정하며 작업마다 수용 개수 1을 소비한다. 목표는 비용 합이다. 입력은 최대 8개 작업·4개 자원으로 제한한다.

검증은 손계산한 합계 3, greedy는 실패하지만 유효한 배정이 존재하는 사례, greedy 비용 101에 비해 정확한 작은 모델은 4인 사례, 정원/금지 배정·입력 경계를 포함한다. 실제 테스트에서 실행한 범위만 근거로 삼는다. 한 예제에서 greedy가 최적이었다고 일반 최적성을 주장하지 않는다.

다른 과제에 적용할 때 입력·출력 어댑터, 합의한 필수 조건, 비용/단위, 직접 계산한 작은 정답과 기준선을 바꾼다. 생성 결과와 사람이 수정한 결과는 같은 평가기를 거치게 할 수 있다. 비최적화 판정 기능이라면 전수 탐색 대신 고정된 판정표와 경계 기대값을 사용한다. 큰 실제 입력에 `exact_tiny`를 확장해 사용하지 않는다.

이후 `fde-core-review`로 결정 대상·필수 조건/목표·선택 이유·실제 검증·한계를 기존 WORK에 연결한다. 화면 E2E와 계산 검증을 구분한다.
