# 자체 연습 과제: 교육 등록 현황

운영 담당자 요청:

“등록 이력이 여러 번 쌓여 있어서 코호트별 현황이 맞지 않아요. 첨부 CSV에서 현재 확정 인원과 확정률을 정리하고, 확인이 필요한 자료도 따로 알려주세요. 결과는 제가 동료에게 파일로 전달할 수 있으면 됩니다.”

자료: [registrations.csv](registrations.csv). 코드는 제공되지 않는다. 필요한 정책은 담당자에게 질문한다. 화면·인증·DB·AI 기능이 필수라는 요구는 없다.

60분 안에 질문→확인된 요구→계획→가능한 최소 산출물→실제 기대값 검증을 진행한다. 계획만 연습하려면 REHEARSAL 가이드의 60분 구성을 따른다. 실제 출제/공식 평가 자료가 아니다.

담당자 설정은 FACILITATOR.md에 있다. 응시자 역할은 연습 종료 전 읽지 않는다. 이미 본 경우에는 절차 연습으로 구분한다.
