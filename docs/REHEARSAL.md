# 연습 가이드

하루 1시간이면 각 회차의 결과를 작게 고정한다. 이미 읽은 과제를 다시 풀면 절차 연습으로 기록하고 처음 보는 업무 대응 점수로 해석하지 않는다.

| 회차 | 시간 배분 | 남길 결과 |
|---|---|---|
| 실행/구조 | 15분 실행·15분 세 예제·20분 정의/확장 탐색·10분 설명 | 실행 명령, 정의→엔진→화면 경로 |
| 질문/계획 | 5분 자료·15분 인터뷰·15분 요구표·15분 계획·10분 설명 | 출처·완료 조건·첫 흐름·미확인 |
| 새 도메인 | 10분 요구표·25분 정의/흐름·15분 경계·10분 기록 | 실제 입력→결과, 실패 사례 |
| 중간 변경 | 10분 변경 정책·25분 구현·15분 회귀·10분 설명 | 기존/신규 건 비교, 유지한 조건 |
| 조직 권한 | 10분 역할표·25분 역할 전환·15분 거부 사례·10분 설명 | 자기 승인·타회사·위임 취소·예산 |

전체 모의 시험은 실제 작업 제한과 후속 답변 시간을 따로 확보해 수행한다. 짧은 1시간 연습을 풀타임 리허설 두 번으로 계산하지 않는다. [WORK](templates/WORK.md)에 첫 실제 결과 시각, 설치/질문/오류 수정 시간, 놓친 조건, 불필요한 변경을 남긴다.

질문 연습은 제3자/가상 진행자가 고정 정책을 보관하고 질문한 범위에 답하도록 한다. 진행자 설정을 미리 봤다면 블라인드라고 부르지 않는다. [등록 현황 분석 BRIEF](drills/registration-analysis/BRIEF.md)를 사용할 수 있고 [FACILITATOR](drills/registration-analysis/FACILITATOR.md)는 진행자용이다.

마지막 10분에는 AI 없이 다음을 설명한다: 질문한 이유, 선택한 데이터/권한 모델, 직접 구현한 부분, 실제 검증, 남은 한계. 모르는 부분을 숨기지 않는다. 이 연습 기록을 공식 평가 점수/경쟁률/합격 가능성으로 환산하지 않는다.
