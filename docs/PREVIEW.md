# 제공 환경의 미리보기 실행

제공 안내가 서버를 0.0.0.0에 바인딩하도록 요구하는 경우 이 경로를 쓴다. 기본 로컬 실행은 127.0.0.1이고, 아래 실행기만 명시적으로 모든 네트워크 인터페이스를 사용한다. 실제 평가 환경의 JDK/다운로드/포트 전달은 해당 환경에서 확인해야 한다.

## 1. 프론트와 서버 JAR 준비

저장소 최상위에서 실행한다. Java 21과 실제 제공 환경에서 허용된 네트워크가 필요하다. 같은 프로젝트 서버가 실행 중이면 그 서버를 정상 종료한 뒤 빌드한다.

```bash
./npmw ci --no-audit --no-fund
./npmw run webapp:build:dev
./mvnw -ntp -Dskip.installnodenpm -Dskip.npm verify
```

이 경로는 React 정적 화면과 API를 한 서버 포트로 제공한다. Vite 개발 서버를 별도로 열 필요가 없다. JAR가 이미 있고 소스가 같으면 설치/빌드를 반복하지 않고 다음 단계로 간다.

## 2. 0.0.0.0으로 실행

```bash
./scripts/preview.sh 8080
```

기본 포트는 8080이며 첫 인수로 다른 포트를 지정할 수 있다. 서버 준비 완료와 **실제로 사용한 포트**를 Spring Boot 시작 로그에서 확인한다. 예시의 8080이나 플랫폼 입력창의 기본 3000을 무조건 사용하지 않는다. 포트 충돌로 시작에 실패하면 사용 가능한 포트를 골라 다시 실행한다.

실행기의 실제 애플리케이션 인수는 다음과 같다.

```bash
./scripts/run-jar.sh --server.address=0.0.0.0 --server.port=8080
```

서버는 현재 터미널의 foreground에서 실행한다. 미리보기를 확인하는 동안 이 터미널을 유지한다. 종료는 Ctrl+C다. 이 실행기는 자동 시작 서비스나 터미널 종료 후 생존을 등록하지 않는다.

## 3. 플랫폼 미리보기 연결

1. PORT에 **서버 로그에서 확인한 실제 포트**를 입력한다.
2. URL/경로 영역에 `/fde`를 입력한다. `/`는 홈 화면이고 업무 화면은 `/fde`다.
3. 오른쪽 새로고침/연결 버튼을 누른다.
4. 로그인 뒤 입력·버튼·상세·상태 동작·화면 이동을 직접 확인한다. 로컬 합성 계정은 user/user, admin/admin이다. 실제 과제에서 필요한 계정/정책은 별도로 적용한다.

`0.0.0.0`은 서버가 듣는 주소이며 플랫폼 URL/경로 입력값이 아니다. 사용자 Mac의 localhost 주소를 원격 미리보기 주소로 옮겨 적지 않는다. 제공 플랫폼의 포트 연결 기능을 사용한다.

## 다른 실행 방식

Maven 개발 실행은 다음처럼 같은 옵션을 전달할 수 있다.

```bash
./scripts/dev.sh '-Dspring-boot.run.arguments=--server.address=0.0.0.0 --server.port=8080'
```

조직 합성 데모는 빌드 후 아래 명령을 쓰고 실제 포트를 확인한다. 플랫폼 경로는 `/organization` 또는 `/fde`다.

```bash
./scripts/enterprise-demo.sh --server.address=0.0.0.0
```

기본/조직 데모의 DB가 다르며, 같은 파일 DB를 두 프로세스가 동시에 열지 않는다. 실제 사용자 Mac의 루프백 데모를 원격 미리보기 실행으로 일괄 바꾸지 않는다. 제공 환경의 요구가 있을 때 선택한다.

## 연결이 안 될 때

- 서버가 준비 완료 상태인지, 시작 실패/포트 충돌이 없는지 확인한다.
- 0.0.0.0에 바인딩됐는지와 실제 포트·입력 경로가 일치하는지 확인한다.
- 서버를 실행한 터미널이 살아 있는지 확인한다.
- 화면 변경 뒤 프론트/JAR를 재빌드하고 서버를 재시작했는지 확인한다.
- 로컬 접속 성공만으로 플랫폼의 포트 전달까지 성공했다고 기록하지 않는다.
- 플랫폼 관리·감독·보안 설정을 수정하거나 임의 외부 터널을 열지 않는다.

2026-10-30 로컬에서 실제 임시 서버의 wildcard 바인딩, 업무 화면, 인증 후 catalog를 확인했다. 공식 Cofa 환경의 미리보기 연결과 사용자 버튼 조작은 별도 확인 대상이다.
